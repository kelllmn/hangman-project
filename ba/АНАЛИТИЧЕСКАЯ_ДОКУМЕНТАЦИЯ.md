1. Исследование 

   1. Анализ конкурентов 

| Критерий  | Классическая «Виселица»  | Наш проект  |
| :---- | :---- | :---- |
| Подсказки  | Отсутствуют/платные  | Бесплатные, даются за правильный ответ на вопрос  |
| Обучающий элемент  | Нет  | Двойной: вопрос \+ подсказка к слову  |
| Риск угадывания  | Высокий  | Снижается через эрудицию игрока  |

    

   2. Анализ целевой аудитории 

      * Аудитория: Студенты, желающие подтянуть лексику русского языка, либо просто любители головоломок. 

      * Потребности пользователей:    
        o Ситуация: У студента есть 10 минут свободного времени в транспорте или на перерыве между парами. o Мотивация: Пользователь хочет развлечься, но при этом размять мозги и выучить пару новых слов. o Ожидание: Игра не должна быть лёгкой или абсолютно невозможной. 

           
         

2. Проектирование 2.1. Концепция системы подсказок 

   Игрок может получить подсказку, только правильно ответив на вопрос из случайной категории. В отличие от классической модели с накоплением валюты, здесь «платёж» — это проверка знаний. 

   2. Типы вопросов 

| Категория  | Пример  | Формат ответа  | Сложность  |
| :---- | :---- | :---- | :---- |
| Эрудиция  | В каком году началась Вторая мировая война? (1939)  | Ввод числа  | Средняя    |
| Эрудиция  | Какова высота Эйфелевой башни? (300)  | Ввод числа  | Средняя  |
| Математика  | 15\*24= (360)  | Ввод числа  | Средняя  |
| Математика  | Продолжить  ряд: 1, 4, 9, 16, 25, ? (36)  | Ввод числа  | Легкая  |

       

   3. Пользовательские сценарии  

Сценарий 1: Получение подсказки  

Предусловие: Игрок находится в основном цикле игры, слово частично угадано. 

| Шаг  | Действие  | Реакция системы  |
| :---- | :---- | :---- |
| 1  | Игрок нажимает кнопку «Лампочка»  | Система проверяет доступность подсказки  |
| 2  |   | Подсказка доступна. Выбирается случайный вопрос  |
| 3  |   | Отображается окно с вопросом  |
| 4  | Игрок вводит правильный ответ  | Окно закрывается, система активирует подсказку  |
| 5  |   | Действие подсказки отображается на экране  |
| 6  | Игрок продолжает угадывать слово  |   |

 

Сценарий 2: Провал вопроса 

| Шаг  | Действие  | Реакция системы  |
| :---- | :---- | :---- |
| 1  | Игрок вводит неверный ответ  | Система подсвечивает ошибку  |
| 2  |   | Окно закрывается. Кнопка «Лампочка» блокируется  |
| 3  |   | Подсказка не предоставляется  |
| 4  | Игрок продолжает без подсказки  |   |

Сценарий 3: Повторный запрос подсказки 

Предусловие: Игрок уже запрашивал подсказку для этого слова 

| Шаг  | Действие  | Реакция системы  |
| :---- | :---- | :---- |
| 1  | Игрок нажимает кнопку «Лампочка»  | Система проверяет статус  |
| 2  |   | Подсказка уже использована или заблокирована  |
| 3  |   | Кнопка неактивна, ничего не происходит  |

 

Сценарий 4: Закрытие вопроса без ответа 

| Шаг  | Действие  |   |
| :---- | :---- | :---- |
| 1  | Игрок нажимает  «Вернуться к игре»  | Окно закрывается  |
| 2  |   | Штраф не начисляется  |
| 3  |   | Кнопка «Лампочка» остается активной  |
