# Аналитическая документация — SADT/IDEF0

**Проект:** Игра «Виселица» с обучающей системой подсказок  
**Методология:** SADT (Structured Analysis and Design Technique), нотация IDEF0

---

## 1. Назначение и точка зрения

**Назначение модели:** описать функциональную структуру игры «Виселица» — что система делает, какие данные потребляет и производит, какими правилами и ресурсами управляется.

**Точка зрения:** разработчик учебного приложения на PyQt6/Python.

**Аудитория:** студенты среднего уровня Python (ООП, функции, структуры данных).

---

## 2. Контекстная диаграмма A-0

Вся система рассматривается как единый функциональный блок.

```
                        ПРАВИЛА ИГРЫ
                   БАНК СЛОВ  БАНК ВОПРОСОВ
                        │
          ┌─────────────▼─────────────┐
          │                           │
ДЕЙСТВИЯ  │   ПРОВЕСТИ ИГРОВОЙ СЕАНС  │──► РЕЗУЛЬТАТ РАУНДА
ИГРОКА ──►│          ВИСЕЛИЦА         │    (победа / поражение)
          │                           │──► ПРИОБРЕТЁННЫЕ ЗНАНИЯ
          │          [ A-0 ]          │    (открытые Python-факты)
          └─────────────┬─────────────┘
                        │
                 PyQt6-ПРИЛОЖЕНИЕ
                    PYTHON 3.10+
```

### Описание стрелок A-0

| Тип | Стрелка | Описание |
|---|---|---|
| **I** Вход | Действия игрока | Нажатие букв, кнопки «Подсказка», «Новая игра» |
| **C** Управление | Правила игры | Лимит ошибок (10), условия победы/поражения |
| **C** Управление | Банк слов | JSON-файл с русскими словами и описаниями |
| **C** Управление | Банк вопросов | JSON-файл с Python-вопросами трёх типов |
| **O** Выход | Результат раунда | Победа или поражение с раскрытием слова |
| **O** Выход | Приобретённые знания | Факты по Python, усвоенные при ответе на вопрос |
| **M** Механизм | PyQt6-приложение | Графическая оболочка (виджеты, диалоги) |
| **M** Механизм | Python 3.10+ | Среда выполнения |

## 3. Диаграмма A0 — Декомпозиция контекстного блока

Функция «Провести игровой сеанс Виселица» разбивается на четыре блока.

```
                  ПРАВИЛА ИГРЫ    БАНК СЛОВ    БАНК ВОПРОСОВ
                       │              │               │
                       │         ┌────▼────┐          │
                       │         │         │          │
ДЕЙСТВИЯ               │ Слово   │  A1     │ Скрытое  │
ИГРОКА ────────────────┼────────►│ ИНИЦ.   │ слово ───┼──────────────┐
(нажатие букв,         │         │ РАУНДА  │          │              │
 кнопок)               │         └─────────┘          │              │
        │              │                              │              │
        │         ┌────▼──────────────────────────┐   │              │
        └─────────►                               │   │              │
                  │  A2  ОБРАБАТЫВАТЬ ХОД ИГРОКА  │◄──┘              │
                  │                               │                  │
                  └──────┬──────────┬─────────────┘                  │
              Угаданная  │          │ Ошибка                         │
              буква      │          │                                │
                         │     ┌────▼──────────────────────┐         │
                         │     │  A3  УПРАВЛЯТЬ СИСТЕМОЙ   │◄────────┘
                         │     │       ПОДСКАЗОК           │
                         │     └────────────────┬──────────┘
                         │           Открытая   │
                         │           буква      │
                         │     ┌────────────────▼──────────┐
                         └────►│  A4  ОПРЕДЕЛИТЬ РЕЗУЛЬТАТ │
                               │          РАУНДА           │
                               └────┬──────────┬───────────┘
                                    │          │
                              Победа│          │ Поражение
                                    ▼          ▼
                             РЕЗУЛЬТАТ РАУНДА
                         ПРИОБРЕТЁННЫЕ ЗНАНИЯ (из A3)
```

### Описание блоков A0

#### A1 — Инициализировать раунд

| Тип | Стрелка |
|---|---|
| **I** | — (запускается при старте или «Новая игра») |
| **C** | Банк слов, Правила игры |
| **O** | Скрытое слово (список символов ■), Описание слова |
| **M** | `game_logic.get_word_and_description()`, `create_hidden_word()` |

Выбирает случайное слово из JSON, формирует скрытое слово из символов ■, сбрасывает счётчик ошибок и флаг `hint_used`.

---

#### A2 — Обрабатывать ход игрока

| Тип | Стрелка |
|---|---|
| **I** | Нажатая буква (действие игрока), Скрытое слово |
| **C** | Правила игры (лимит ошибок = 10) |
| **O** | Обновлённое скрытое слово, Ошибка (если буква не в слове) |
| **M** | `game_logic.update_hidden_word()`, кнопки алфавита (HangmanGame) |

Блокирует кнопку после нажатия. Если буква угадана — открывает все её вхождения. Если нет — увеличивает счётчик ошибок и дорисовывает виселицу.

---

#### A3 — Управлять системой подсказок

| Тип | Стрелка |
|---|---|
| **I** | Запрос подсказки (кнопка «Подсказка»), Скрытое слово |
| **C** | Банк вопросов (questions.json), Флаг hint_used |
| **O** | Открытая буква (при успехе), Заблокированная кнопка «Подсказка» |
| **M** | `QuestionBank`, `HintDialog`, `HangmanGame.reveal_random_letter()` |

*Декомпозируется в A3 (см. раздел 4).*

---

#### A4 — Определить результат раунда

| Тип | Стрелка |
|---|---|
| **I** | Обновлённое скрытое слово, Счётчик ошибок |
| **C** | Правила игры (победа: нет ■; поражение: ошибок = 10) |
| **O** | Результат раунда (победа / поражение), Приобретённые знания |
| **M** | `HangmanGame.show_message()`, `QMessageBox` |

При победе — показывает поздравление. При поражении — раскрывает слово. В обоих случаях предлагает начать новый раунд.

## 4. Диаграмма A3 — Декомпозиция «Управлять системой подсказок»

```
         БАНК ВОПРОСОВ      ФЛАГ hint_used
                │                  │
         ┌──────▼──────┐           │
         │             │           │
ЗАПРОС   │  A3.1       │ Вопрос    │
ПОДСКАЗКИ│  ВЫБРАТЬ    │──────────►│
─────────►  ВОПРОС     │           │
         │             │           │
         └─────────────┘      ┌────▼───────────────────┐
                              │  A3.2                  │
                              │  ПОКАЗАТЬ ДИАЛОГ       │◄── Скрытое слово
                              │  ПОДСКАЗКИ             │
                              └─────┬───────────┬──────┘
                          Правильный│    Неверн.│  Отмена
                          ответ     │    ответ  │  (без ответа)
                                    │           │
                        ┌───────────▼─┐   ┌─────▼──────────────┐
                        │  A3.3       │   │  A3.4              │
                        │  ОТКРЫТЬ    │   │  ЗАБЛОКИРОВАТЬ     │
                        │  СЛУЧАЙНУЮ  │   │  КНОПКУ «Подсказка»│
                        │  БУКВУ      │   │                    │
                        └──────┬──────┘   └───────┬────────────┘
                               │                  │
                        Открытая буква     Подсказка была использована
                               │                  │
                               └──────────────────┘
                                        │
                                  (выход из A3)
                               При отмене — кнопка
                               «Подсказка» остаётся активной
```

### Описание блоков A3

#### A3.1 — Выбрать вопрос

| Тип | Стрелка |
|---|---|
| **I** | Запрос подсказки |
| **C** | Банк вопросов, множество использованных ID |
| **O** | Объект вопроса (dict: id, type, question, correct, ...) |
| **M** | `QuestionBank.get_random_question()`, `mark_used()` |

Возвращает случайный неиспользованный вопрос. Если банк исчерпан — вызывает `reset_session()` автоматически.

---

#### A3.2 — Показать диалог подсказки

| Тип | Стрелка |
|---|---|
| **I** | Объект вопроса, Скрытое слово (для проверки наличия ■) |
| **C** | Тип вопроса (`choice` / `input` / `code`) |
| **O** | Результат диалога: правильный ответ / неверный ответ / отмена |
| **M** | `HintDialog(QDialog)` |

Три режима UI в зависимости от типа:
- **choice** — 4 кнопки с вариантами
- **input** — `QLineEdit` для ввода
- **code** — моноширинный блок кода + `QLineEdit` для пропуска

---

#### A3.3 — Открыть случайную букву

| Тип | Стрелка |
|---|---|
| **I** | Правильный ответ (сигнал из A3.2), Скрытое слово |
| **C** | — |
| **O** | Обновлённое скрытое слово с одной раскрытой буквой |
| **M** | `HangmanGame.reveal_random_letter()`, `update_hidden_word()` |

Выбирает случайную позицию с символом ■, открывает соответствующую букву слова на всех её вхождениях.

---

#### A3.4 — Заблокировать кнопку «Подсказка»

| Тип | Стрелка |
|---|---|
| **I** | Неверный ответ (сигнал из A3.2) |
| **C** | — |
| **O** | `hint_used = True`, `hint_button.setEnabled(False)` |
| **M** | `HangmanGame.on_hint_clicked()` |

Блокирует кнопку до конца раунда. Вызывается и после успешного ответа (после A3.3), чтобы исключить повторное использование.

## 5. Пользовательские сценарии

### Сценарий 1: Успешная подсказка

| Шаг | Блок IDEF0 | Действие | Результат |
|---|---|---|---|
| 1 | A3.1 | Игрок нажимает «Подсказка» | Выбран случайный неиспользованный вопрос |
| 2 | A3.2 | Открыт диалог `HintDialog` | Показан вопрос нужного типа |
| 3 | A3.2 | Игрок вводит правильный ответ | Диалог возвращает `Accepted` |
| 4 | A3.3 | Система открывает букву | Скрытое слово обновлено |
| 5 | A3.4 | Кнопка «Подсказка» блокируется | `hint_used = True` |

### Сценарий 2: Неверный ответ

| Шаг | Блок | Действие | Результат |
|---|---|---|---|
| 1 | A3.1 | Нажатие «Подсказка» | Вопрос выбран |
| 2 | A3.2 | Игрок вводит неверный ответ | Диалог показывает ошибку, возвращает `Rejected` |
| 3 | A3.4 | Кнопка «Подсказка» блокируется | Буква не открывается |

### Сценарий 3: Отмена диалога

| Шаг | Блок | Действие | Результат |
|---|---|---|---|
| 1 | A3.1 | Нажатие «Подсказка» | Вопрос выбран |
| 2 | A3.2 | Нажата «Вернуться к игре» | `submitted = False`, `Rejected` |
| 3 | — | Кнопка «Подсказка» остаётся активной | `hint_used` не изменился |

### Сценарий 4: Повторная попытка

| Шаг | Блок | Действие | Результат |
|---|---|---|---|
| 1 | A2 | Нажатие «Подсказка» при `hint_used = True` | `hint_button.isEnabled() == False`, ничего не происходит |

## 6. Граничные случаи (Edge Cases)

| Ситуация | Затронутый блок | Ожидаемое поведение |
|---|---|---|
| Банк вопросов исчерпан | A3.1 | `reset_session()` → вопросы доступны снова |
| Все буквы открыты | A3.2 | Кнопка «Подсказка» неактивна, диалог не открывается |
| Слово из 1 оставшейся буквы | A3.3 | Открывается последняя буква → немедленная победа |
| Ответ с другим регистром | A3.2 | Проверка без учёта регистра (`strip().lower()`) |
| Нажатие «Подсказка» до первого хода | A3.1–A3.3 | Работает корректно, открывается случайная буква |

---

## 7. Критерии приёмки

- [ ] A1: Новый раунд инициализируется случайным словом
- [ ] A2: Кнопки алфавита блокируются после нажатия
- [ ] A3.1: Вопросы не повторяются до полного исчерпания банка
- [ ] A3.2: Поддерживаются все три типа (`choice`, `input`, `code`)
- [ ] A3.3: Правильный ответ открывает одну случайную букву
- [ ] A3.4: Неверный ответ блокирует кнопку «Подсказка» без открытия буквы
- [ ] A3: Отмена диалога не штрафует и не блокирует кнопку
- [ ] A4: Победа фиксируется при отсутствии ■ в скрытом слове
- [ ] A4: Поражение фиксируется при 10 ошибках

## 8. Глоссарий стрелок модели

| Стрелка | Тип | Описание |
|---|---|---|
| Действия игрока | I | Пользовательские события: нажатие буквы, кнопок |
| Правила игры | C | Константы: 10 ошибок = поражение, условие победы |
| Банк слов | C | `words.json` — список слов с описаниями |
| Банк вопросов | C | `questions.json` — 18 вопросов трёх типов |
| Флаг hint_used | C | Булев флаг раунда: подсказка использована или нет |
| Скрытое слово | I→O | Список символов; ■ = не угадано, буква = открыто |
| Объект вопроса | O→I | dict: `{id, type, question, correct, options?, hint_for_code?}` |
| Открытая буква | O | Буква слова, переданная в `update_hidden_word()` |
| Результат раунда | O | «Победа» или «Поражение» + раскрытое слово |
| Приобретённые знания | O | Python-факт, усвоенный при правильном ответе |
| PyQt6-приложение | M | Реализация UI: виджеты, сигналы, диалоги |
| Python 3.10+ | M | Среда выполнения, стандартная библиотека |
